Langkah Menjalankan Proyek :
1. Persyaratan

    Dowload Android Studio.

    Android SDK.

    Emulator Android atau HP Android.

    Koneksi internet untuk mengunduh dependensi jika diperlukan.

Langkah-langkah
1. Unduh proyek dengan buka repositori GitHub Kelompok 6, klik Code, lalu pilih Download ZIP.
2. Ekstrak berkasZIP ke folder di komputer.
3. Buka proyek dan alankan Android Studio, pilih Open, lalu pilih folder utama proyek yang berisi berkas Gradle.
4. Tunggu sinkronisasi Gradle hingga proses Gradle Sync selesai. Jika diminta, izinkan Android Studio mengunduh dependensi yang diperlukan.
5. Siapkan perangkat dengan pilih emulator Android atau hubungkan HP Android yang telah mengaktifkan USB Debugging.
6. Jalankan aplikasi, Pilih konfigurasi aplikasi, kemudian klik tombol Run ▶ di Android Studio.
7. Uji fitur aplikasi, setelah aplikasi terbuka,
   lakukan pengujian berikut:
    1. Melihat halaman utama dan ringkasan setoran.
    2. Melihat daftar harga berdasarkan jenis sampah.
    3. Menambahkan setoran dengan mengisi nama, jenis sampah, dan berat.
    4. Menguji validasi input yang tidak sesuai aturan.
    5. Melihat daftar setoran dan ringkasan saldo.
    6. Menghapus setoran dan memeriksa perubahan ringkasan.
8. Fitur Aplikasi

   1. Pencatatan setoran sampah.
   2. Pemilihan jenis sampah: plastik, kertas, logam, dan kaca.
   3. Perhitungan nilai setoran berdasarkan berat dan harga per kilogram.
   4. Bonus 10% untuk sampah yang bersih dan terpilah.
   5. Ringkasan jumlah setoran, total berat, dan saldo.
   6. Daftar setoran dan fitur penghapusan data.
